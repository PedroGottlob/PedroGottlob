## 🍽️ Projeto em destaque: Solution Kitchen

Plataforma **SaaS multi-tenant** para gestão de restaurantes (pedidos, mesas, cardápio, cozinha e pagamentos).

- **Arquitetura de microsserviços** em .NET (order, table, menu, payment) com um BFF dedicado
- **Multi-tenancy schema-per-tenant** no PostgreSQL com EF Core e provisionamento automatizado de tenants
- **Comunicação orientada a eventos** com Kafka e atualizações em tempo real via SignalR (KDS, mesas, pagamento)
- **Pagamentos PIX** integrados com Mercado Pago (webhooks)
- **Autenticação e autorização** com Auth0 e controle de acesso por papel
- Tudo orquestrado com **Docker Compose**

`.NET` `C#` `React` `TypeScript` `Kafka` `PostgreSQL` `MongoDB` `Redis` `SignalR` `Auth0` `Docker`
